봇 마켓 심사

기업이 직접 만들어 다른 기업에 공개하려는 봇이에요. 역할 지시문은 운영 기관의 Claude API 비용으로 실행되니, 내용과 토큰 가격을 확인하고 승인하세요.

원작 기업의 요구

원작 기업이 "우리 봇을 복사했다"고 신고한 건이에요. 두 봇의 역할 지시문·만든 날짜·겹침 비율을 보고 폐기할지, 원작 기업으로 연결할지(쓰일 때마다 원작 기업에 토큰), 기각할지 결정하세요. 결과는 양쪽 기업방에 알려요.

복사로 찾은 봇

역할 지시문이 다른 기업이 먼저 만든 봇과 많이 겹치면 원작으로 연결해, 쓰일 때마다 원작 기업에 몫이 가요. 잘못 찾았으면 풀고, 못 찾은 복사는 직접 연결하세요.

게시판

기업의 Q&A(비밀글 포함)에 답하고, 봇 추천 글을 관리해요. 비밀글은 쓴 기업과 운영 기관만 볼 수 있어요.

토큰 API (충전·환전)

충전(mint)·환전(burn)은 블록체인과 같은 인터페이스의 토큰 API를 거쳐요. 지금은 내부 장부로 동작하고, 나중에 실제 블록체인 어댑터로 바꿔요. 원격 충전·환전 페이지는 여기서 발급한 API 키로 서명해서 접근해요.
